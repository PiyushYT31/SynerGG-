# Build Project

This workflow explains how to install dependencies and build the Next.js project.

## Prerequisites
- Node.js >= v20
- npm (comes with Node.js)

## Steps

1. **Install Dependencies**
   Run the following command to install all necessary packages:
   ```bash
   npm install
   ```

2. **Build the Project**
   Compile and build the project for production:
   ```bash
   npm run build
   ```
